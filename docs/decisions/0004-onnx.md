# ADR 0004: Consider ONNX as a model exchange format

- Status: Proposed
- Date: 2026-09-21

## Context

A later inference worker may need a documented, portable model format without
tying the public interface to one training framework.

## Initial decision

Evaluate ONNX as the exchange format in a later part. No external model,
converter, runtime, weight, checkpoint, or download is included.

## Validation still required

Establish model and training-data licences, conversion fidelity, supported
operators, numerical parity, runtime security, resource use, and reproducible
checksums. A format decision does not approve a model for operational use.
